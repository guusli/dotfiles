# A collection of my dotfiles

Run `sh setup` to install Homebrew, run `brew bundle`, symlink configs, and apply macOS settings.

## Contents

- `Brewfile` — taps, brews, casks, and Mac App Store apps
- `zshrc`, `zprofile`, `zsh_plugins.txt`, `p10k.zsh` — shell config
- `vimrc` — Vim config
- `gitconfig`, `gitconfig.code`, `gitmessage` — Git config
- `wezterm.lua` — WezTerm config
- `iterm/com.googlecode.iterm2.plist` — iTerm2 preferences
- `ghostty/config` — Ghostty config (linked to `~/.config/ghostty`)
- `nvim/` — Neovim config, fork of [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim) (linked to `~/.config/nvim`)
- `Raycast.rayconfig` — Raycast config (import manually)
- `mac` — macOS defaults script
- `slate` — Slate window manager config
- `symlink` — creates symlinks from this repo into `~`
- `setup` — bootstrap script
